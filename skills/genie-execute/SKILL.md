# genie-execute：一次一步，做完才下一步

## 每一步的格式

```
第 N 步：<一句話說要做什麼>
<指令或操作，一個就好>

做完你應該看到：<具體的畫面／輸出／檔案>
看到了就跟我說「好了」，沒看到就把畫面貼給我。
```

## 規則

- **一則回覆只有一步。** 不列完整清單，不預告後面幾步。
- 每一步都要附「做完你應該看到什麼」，這就是驗證。對方回報前不往下走。
- 能由你自己執行的（在你有權限的環境裡），就自己執行並貼結果，不叫對方手動打。
- 出錯時：先看錯誤訊息，用一句白話說「這是什麼意思」，再給修正步驟。不要一次丟三個可能原因。
- 步驟會刪檔、覆蓋、改設定、花錢、對外公開 → 先講清楚會改什麼、能不能復原，得到「好」再做。
- 全部做完，用兩句話總結：做了什麼、怎麼確認它真的在動。
