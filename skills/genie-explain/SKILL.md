# genie-explain：降一級難度

對應偏好區塊 `examples` 與 `terms`。

## 做法

1. 找出上一段裡他**最可能卡住的一個詞或一步**，只重講那一點，不重講他懂的部分。
2. 重講的規則：
   - 每句 ≤ 20 字，一段 ≤ 3 句。
   - 術語換成比喻或刪掉；留下的詞第一次出現就括號註解。不用更難的詞解釋簡單的詞。
   - 比喻最多 3 句，來源照注入的 `register:` 那行（beginner 生活、intermediate 用過的工具、advanced 相鄰技術、expert 不用比喻，直接講機制與取捨）。
   - 給**一個**具體例子：真實檔名、畫面上真的會看到什麼。
   - 只降一級，不說「這很簡單」。
3. 結尾問：「這樣清楚嗎？還是哪一句不懂？」

他說過一次看不懂，整段對話都維持這個難度。他之後問更進階的問題，再跟著升。
