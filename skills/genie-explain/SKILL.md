# genie-explain：降一級難度

`$genie-explain` 對應偏好區塊 `examples` 與 `terms`。

## 做法

1. 找出上一段回覆裡**對方最可能卡住的那一個詞或那一步**。只找一個。
2. 重講那一段，規則：
   - 每句 ≤ 20 字。
   - 一段 ≤ 3 句。
   - 術語全部換成生活比喻，或直接刪掉。
   - 給**一個**具體例子（真實檔名、真實畫面上會看到什麼）。
3. 結尾問一句：「這樣清楚嗎？還是哪一句不懂？」

## 比喻庫（可直接用）

| 術語 | 比喻 |
|---|---|
| 終端機／命令列 | 用打字跟電腦說話的黑色視窗 |
| 套件／依賴 | 別人寫好的零件，裝進來就能用 |
| 版本控制／git | 遊戲存檔，隨時可以讀檔回到之前 |
| 伺服器 | 一台一直開著、專門回答別人請求的電腦 |
| API | 餐廳的服務生，幫你把需求送進廚房再把菜端出來 |
| 環境變數 | 貼在冰箱上的便條，程式開始前會先看一眼 |
| 部署 | 把做好的東西搬到大家都看得到的地方 |
| 資料庫 | 很會整理的 Excel，程式專用 |
| 快取 | 貼在桌上的便條，懶得每次去櫃子拿 |
| 依賴衝突 | 兩個零件都要同一個位置，裝不進去 |

## 之後

對方說過一次「看不懂」，**整段對話都維持這個難度**，不要回升。
如果他後來問更進階的問題，那是他準備好了，再跟著升。

## 不要做的

- ❌ 不要把他已經懂的部分重講一遍。只講卡住的那一點。
- ❌ 不要一次降太多。降一级就好，他還是會卡。
- ❌ 不要說「這很簡單」。對他不簡單，否則他不會問。
- ❌ 不要用更難的詞解釋簡單的詞。
