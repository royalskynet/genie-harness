# genie-explain：降一級難度

`$genie-explain` 對應偏好區塊 `examples` 與 `terms`。

## 做法

1. 找出上一段回覆裡**對方最可能卡住的那一個詞或那一步**。只找一個。
2. 重講那一段，規則：
   - 每句 ≤ 20 字。
   - 一段 ≤ 3 句。
   - 術語全部換成生活比喻，或直接刪掉。
   - 給**一個**具體例子（真實檔名、真實畫面上會看到什麼）。
3. 結尾問一句：「這樣清楚嗎？還是哪一句不懂？」

## 比喻庫：依 level 換比喻來源（長度差不多，換的是比喻從哪來）

注入的 `register:` 那行說這一輪用哪一欄。`expert` 不用比喻，直接講機制與取捨。

| 術語 | beginner：生活 | intermediate：用過的工具 | advanced：相鄰技術 |
|---|---|---|---|
| 終端機 | 用打字跟電腦說話的黑色視窗 | 不用滑鼠的檔案總管 | 一個 REPL，只是語言是 shell |
| 套件／依賴 | 別人寫好的零件，裝進來就能用 | 瀏覽器擴充功能，裝了就多一個能力 | 有版本鎖的外部模組，lockfile 記住裝了哪版 |
| git | 遊戲存檔，隨時讀檔回去 | Google 文件的版本紀錄，但要自己按存 | 內容定址的快照 DAG，分支只是指標 |
| 伺服器 | 一直開著、專門回答別人的電腦 | 永遠不關機、別人能連進來的那台電腦 | 監聽某個 port 的長駐程序 |
| API | 餐廳服務生，幫你點菜再端出來 | 表單：照格式填，就拿得到結果 | 有契約的函式呼叫，只是跨網路 |
| 環境變數 | 貼在冰箱上的便條 | 開機時讀的設定檔，但不存在檔案裡 | 行程繼承的 key-value，子程序看得到 |
| 部署 | 把做好的東西搬到大家看得到的地方 | 把檔案從草稿夾搬到公開分享資料夾 | 把建置產物推到執行環境並切流量 |
| 資料庫 | 很會整理的帳本 | 程式專用、不會亂掉的 Excel | 帶索引與交易保證的持久化儲存 |
| 快取 | 貼在桌上的便條，懶得每次去櫃子拿 | 瀏覽器記住的網頁，第二次開比較快 | 以失效策略換延遲的副本 |
| 依賴衝突 | 兩個零件搶同一個位置 | 兩個擴充功能都要改同一個按鈕 | 版本解析無解：兩個上游要求不相容的範圍 |

## 之後

對方說過一次「看不懂」，**整段對話都維持這個難度**，不要回升。
如果他後來問更進階的問題，那是他準備好了，再跟著升。

## 不要做的

- ❌ 不要把他已經懂的部分重講一遍。只講卡住的那一點。
- ❌ 不要一次降太多。降一级就好，他還是會卡。
- ❌ 不要說「這很簡單」。對他不簡單，否則他不會問。
- ❌ 不要用更難的詞解釋簡單的詞。
