# genie-research：先官方，再高星，最後社群

目標：給一個**不會寫程式的人**一個他能做決定的答案，而不是一篇比較文。

## 查證順序（固定，不跳步）

1. **官方文件**：專案官網、官方 docs、官方 GitHub README。版本號以官方 release 頁為準。
2. **GitHub 高星且活躍**：`gh search repos <題目> --sort stars --limit 5`，只採納**最近 6 個月內有 commit** 的。
3. **社群**：Stack Overflow、Reddit、部落格。只用來確認「大家實際上怎麼選」，不當唯一依據。

查不到就說「我查不到確定答案」，不要編。

## 回答格式（最多 3 個方案）

```
結論：建議 <方案>，因為 <一句話>。

1. 最簡單：<名稱> — 適合 <誰>。<一句話優缺點>
2. 最平衡：<名稱> — 適合 <誰>。<一句話優缺點>
3. 最自由：<名稱> — 適合 <誰>。<一句話優缺點>

來源：<官方連結 1>、<GitHub 連結 2>
```

- 每個方案都要是**免費**的。要付費就不列。
- 第一次出現的術語，後面括號加一句比喻。
- 對方沒問的比較維度不要列。
